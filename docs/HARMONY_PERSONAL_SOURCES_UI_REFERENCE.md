# 鸿蒙实机：日历与邮箱界面参考

观察日期：2026-11-04。通过HDC连接用户已授权的鸿蒙手机，浏览已安装的
com.coevomind.clawmate。仅打开页面、返回和滚动，没有切换设置、保存、同步或登录邮箱。
截图留在忽略目录，不导入原端账号、数据库或设备配置。以下为实机观察，不是源码推测；
安装包版本与源码提交的对应关系尚未核验。

## 共同视觉结构

- 淡灰蓝背景、白色分组卡片，大圆角；卡片内部是列表行及浅色分隔线。
- 固定居中粗体标题，左侧白色方形圆角返回按钮；滚动时顶部呈毛玻璃效果。
- 分组标题与说明使用低对比灰蓝色，说明在卡片外；输入项有持续可见的字段名称。
- 操作以卡片内蓝色文字行呈现，删除以红色文字呈现，不是整页密集的蓝色胶囊按钮。
- 页面之间没有互相切换按钮；原端仍显示底部六入口，Android现阶段保留既有五入口。

## 汇总

“采集与分析”同一白色卡片依次为：新增采集源、图库分析、日历分析、邮箱分析。
日历为棕橙色日历图标，副标题“日程同步与一周安排”；邮箱为蓝紫色信封图标，
副标题“邮箱设置与近三天邮件筛选”。每行右端有进入箭头，日历/邮箱行另有独立同步按钮。
观察时邮箱同步按钮灰置；未点击同步验证业务行为。

## 日历分析

1. “接入系统日历”开关及系统授权说明。
2. “记忆与提醒”卡片：历史读取范围（观察值过去90天）、参与个人画像开关。
3. 说明未来读取30天、首页提醒未来7天与进行中安排；历史供聊天检索，未来计划不是已完成经历。
4. “日历来源”列表，每行右侧勾选标记；说明公共订阅日历不参与读取。
5. 蓝色“读取并同步记忆”操作行，下方红色清除日历记忆操作。

没有切换来源、调用读取或查看个人日程内容；开关状态仅为当前设备状态，不作为Android默认值。

## 邮箱分析

1. “开启邮件提醒”开关；说明跨天首次打开自动更新、也可汇总同步，保留今天及前两天。
2. “邮箱账号”表单卡片：邮箱类型、账号、IMAP服务器、TLS端口、客户端授权码（可见性按钮）。
3. “智能筛选”：允许AI筛选开关及数据用途说明，关闭时仅本机阅读，邮件不进入个人画像。
4. “同步”：每天读取上限（观察值50封）、保存并读取近三天邮件、仅保存设置。
5. 原端当前文案明确不支持Outlook/Gmail OAuth；Android已增加OAuth实现，不能照搬该限制。
